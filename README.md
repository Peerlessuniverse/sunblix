# SUNBLIX — Power Your World

Situs resmi dan pengalaman interaktif sinematik **SUNBLIX**, spesialis solusi terintegrasi PLTS Rooftop (Pembangkit Listrik Tenaga Surya) residensial dan komersial di Indonesia.

---

1. **Cinematic Continuous Camera Hero (Babak 1)**
   - Transisi visual mulus ke hunian bertenaga surya.
   - Trust badges strip (Garansi 25 Tahun, Resmi PLN & SLO ESDM, Tier-1 PV).
   - Indikator interaktif desktop & mobile.

## 🚀 Panduan Deploy ke Vercel

Situs ini dibangun menggunakan arsitektur web statis modern (HTML5, Vanilla CSS, dan JavaScript Native) tanpa build step yang rumit sehingga siap dideploy secara instan di Vercel:

1. Buka [Vercel Dashboard](https://vercel.com/new).
2. Pilih repository: `Peerlessuniverse/sunblix`.
3. Biarkan pengaturan default (*Framework Preset: Other*, *Root Directory: ./*).
4. Klik **Deploy**.
5. Situs akan aktif secara global dengan performa optimal dan SSL otomatis.
